## 维护约定

1. 每个模块 / 窗口结束前必须更新一次，并提交 git。
2. 只写“做了什么、怎么验证、还差什么”，不要复制设计文档的大段内容。
3. 如果改动涉及 API DTO、错误码、DB 字段或路由，先更新设计文档，再在记录里注明“契约已变更”。
4. 下一个窗口开场读：`docs/implementation-handoff.md` + 本文件 + 设计文档相关章节。

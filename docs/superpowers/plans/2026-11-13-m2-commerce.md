# M2 交易域实施计划（购物车 / 地址 / 订单 / 模拟支付发货收货）

**目标：** 在 M1 商品域之上打通「加购 → 购物车 → 结算 → 下单 → 支付 → 客服发货 → 确认收货」完整闭环。

**范围：** 仅 M2；不改 M0 认证契约、不改 M1 商品/收藏 DTO。不实现真实支付、退款、售后、优惠券、评价、物流、发票。

**技术栈：** FastAPI + SQLAlchemy 2 async + PostgreSQL + Alembic；Vue 3 + Vite + TypeScript + Pinia + Vant 4 + Playwright。

### 1.2 表与迁移 `20261113_0003_create_commerce`

- `addresses`：`user_id`、`receiver_name`、`phone`、`province/city/district`、`detail`、`is_default`、时间戳；`ix_addresses_user_id`；部分唯一索引 `uq_addresses_user_default (user_id) WHERE is_default`。
- `cart_items`：`user_id`、`sku_id`、`quantity > 0`、`selected`、时间戳；`UNIQUE(user_id, sku_id)`；`ix_cart_items_user_id`。
- `orders`：`order_no` 唯一、`user_id`、`address_snapshot JSONB`、`total_amount NUMERIC(10,2)`、`status`、`payment_method='simulated'`、`payment_no`、`paid_at/shipped_at/completed_at/cancelled_at`、`expires_at`、时间戳；`ix_orders_user_status`。
- `order_items`：`order_id`、`sku_id`、`product_id`、`title/image/price/color/size` 快照、`quantity > 0`；`ix_order_items_order_id`。
- 状态：`pending_payment / paid / shipped / completed / cancelled`。

### 1.3 接口契约

```text
GET    /api/cart
POST   /api/cart/items            {sku_id, quantity}       -> CartItemOut
PATCH  /api/cart/items/{id}       {quantity?, selected?}   -> CartItemOut
DELETE /api/cart/items/{id}                                  -> 204

GET    /api/addresses
POST   /api/addresses             {receiver_name, phone, province, city, district, detail, is_default?}
PATCH  /api/addresses/{id}
DELETE /api/addresses/{id}                                  -> 204

POST   /api/orders                {address_id, cart_item_ids: []}
GET    /api/orders?status=
GET    /api/orders/{id}
POST   /api/orders/{id}/pay
POST   /api/orders/{id}/cancel
POST   /api/orders/{id}/confirm

GET    /api/agent/orders?status=paid|shipped|completed|all
POST   /api/agent/orders/{id}/ship
```

- 所有用户资源按 `user_id` 过滤；跨用户访问 403，未找到 404；参数/业务校验 400；状态/库存冲突 409；中文提示。
- 购物车返回 `items + total_quantity + selected_count + selected_amount + all_selected`。
- 订单详情返回地址快照、商品快照、金额、状态时间线；客服订单额外返回买家用户名/昵称。
- `cart_item_ids` 为空表示结算当前勾选项；非空表示只结算指定项（立即购买），不改变其他项勾选状态。

### 1.4 库存与订单规则

- 加购只校验库存，不锁库存；同 SKU 加购累加数量，累加后超过库存返回 409，不静默截断。
- 下单事务：`SELECT ... FOR UPDATE OF product_skus`（按 sku_id 排序）→ 校验上架/库存 → 建订单与快照 → 扣库存 → 删除已结算购物车项 → commit。
- 金额内部 `Decimal`，`price = sku.price_override or product.price`，总额逐项累加后写 `NUMERIC(10,2)`。
- 取消/超时：锁订单行，仅 `pending_payment` 可取消；恢复库存和状态变更同一事务，行锁保证只恢复一次；已取消重复取消幂等返回，不重复恢复。
- 超时：`expires_at = now + 15min`；列表/详情/支付前惰性扫描；lifespan 内每 60 秒兜底扫描；`skip_locked` 避免并发阻塞。
- 支付幂等：锁订单行；`pending_payment` 首次支付写 `paid`、假流水号、`paid_at`，并按商品累加 `sales_count`；`paid/shipped/completed` 再次支付直接返回成功且不重复累加；`cancelled` 返回 409。
- 发货仅 `paid → shipped`；确认收货仅 `shipped → completed`；否则 409。

### 2.2 交互与路由

- 新增路由 `/cart`、`/checkout`、`/orders`、`/orders/:id`、`/addresses`（均 `requiresAuth`）；`/agent/orders` 增加 `roles: ['agent','admin']` 守卫，非客服回首页并提示。
- 商品详情：「加入购物车」真实调用；「立即购买」加购后 `router.push('/checkout?items=<cartItemId>')`；未选尺码/缺货给中文提示。
- 首页、分类、详情补 `CartBadge`；进入页面时加载购物车；退出登录/401 清空购物车 store。
- 购物车：勾选/全选/数量步进/删除；库存不足行禁用勾选；空态去逛逛；结算只带勾选项。
- 结算：默认选中默认地址；无地址时引导新增；金额前端展示，后端重算；提交成功跳订单详情。
- 订单：Tab 全部/待付款/待发货/待收货/已完成；待付款可支付/取消，待收货可确认收货；订单详情展示地址与商品快照、时间线。
- 我的：订单/地址入口真实跳转；补待付款/待发货/待收货/已完成快捷入口。
- 客服端：桌面表格布局，待发货/已发货/全部；`模拟发货` 二次确认后刷新；客服登录默认跳 `/agent/orders`。
